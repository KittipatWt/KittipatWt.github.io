1. คำศัพท์ของ Graph

Graph G = (V, E) ประกอบด้วย V เซตจำกัดของ vertex (node) และ E เซตของ edge (arc) ที่เชื่อมคู่ vertex แต่ละเส้นเป็นคู่ (u, v) โดย u, v ∈ V

1.1 ชนิดของ Graph

  • Directed Graph (Digraph): เส้นเป็นคู่อันดับ (u, v) มีทิศ u → v · v เป็น adjacent ของ u แต่ u ไม่จำเป็นต้อง adjacent กับ v
  • Undirected Graph: เส้น (u, v) ไม่มีทิศ ถ้า (u, v) ∈ E แล้ว (v, u) ∈ E โดยนัย
  • Weighted Graph: แต่ละเส้นมีค่าตัวเลข (weight / cost)

1.2 Degree

  • Degree ของ v (undirected): จำนวนเส้นที่ต่ออยู่กับ v
  • In-degree ของ v (directed): จำนวนเส้นที่ชี้ เข้า v · Out-degree: จำนวนเส้นที่ออกจาก v

ตัวอย่าง: กราฟ A → B → C → A · สำหรับ A: in-degree = 1 (จาก C), out-degree = 1 (ไป B), total degree = 2

1.3 Path และ Cycle

  • Path: ลำดับ vertex w₁, w₂, …, wN ที่ (wᵢ, wᵢ₊₁) ∈ E · Path Length = จำนวนเส้น (= N − 1)
  • Simple Path: path ที่ vertex ไม่ซ้ำกัน (ยกเว้นตัวแรกกับตัวสุดท้ายอาจเป็นตัวเดียวกัน)
  • Cycle: path ที่ยาว ≥ 1 และ w₁ = wN · Simple Cycle: cycle ที่เป็น simple (ใน undirected เส้นต้องไม่ซ้ำ)
  • DAG (Directed Acyclic Graph): directed graph ที่ไม่มี cycle

1.4 Connectivity

  • Connected (undirected): มี path จากทุก vertex ไปทุก vertex
  • Strongly Connected (directed): มี path จากทุก vertex ไปทุก vertex (ตามทิศ)
  • Weakly Connected (directed): ถ้าไม่สนทิศของเส้น (underlying undirected graph) แล้ว connected
  • Complete Graph (Kₙ): มีเส้นระหว่างทุกคู่ vertex · undirected complete graph มี |V|(|V| − 1)/2 เส้น

2. การเก็บ Graph (Graph Representations)

ตัวอย่างในหัวข้อนี้ใช้ directed graph 3 vertex: 1 → 2, 2 → 3, 3 → 1

2.1 Adjacency Matrix

array 2 มิติขนาด |V| × |V|: A[i][j] = 1 ถ้ามีเส้น (i, j) ไม่เช่นนั้น 0 (ถ้ามี weight ให้เก็บ weight และใช้ ∞ หรือ 0 แทน "ไม่มีเส้น")

Space O(|V|²) · ข้อดี: เช็กเส้นด้วย O(1) · ข้อเสีย: เปลืองที่มากกับ sparse graph

C++ · AdjacencyMatrixGraph
class AdjacencyMatrixGraph {
private:
    int numVertices;
    vector<vector<int>> adjMatrix;

public:
    AdjacencyMatrixGraph(int vertices) : numVertices(vertices) {
        adjMatrix.resize(vertices, vector<int>(vertices, 0));
    }

    void addEdge(int u, int v, int w = 1) {
        adjMatrix[u][v] = w;            // สำหรับ directed graph
    }

    bool hasEdge(int u, int v) {
        return adjMatrix[u][v] != 0;
    }
};

2.2 Adjacency List

array ของ linked list (หรือ vector) ขนาด |V| · แต่ละ vertex u เก็บ list ของ vertex ที่ adjacent กับ u

Adj[1] → [2] · Adj[2] → [3] · Adj[3] → [1]

Space O(|V| + |E|) · ข้อดี: ประหยัดที่สำหรับ sparse graph · ข้อเสีย: เช็กเส้นต้อง O(degree(u))

C++ · AdjacencyListGraph
class AdjacencyListGraph {
private:
    int numVertices;
    vector<vector<int>> adjList;

public:
    AdjacencyListGraph(int vertices) : numVertices(vertices) {
        adjList.resize(vertices);
    }

    void addEdge(int u, int v) {
        adjList[u].push_back(v);        // สำหรับ directed graph
    }

    bool hasEdge(int u, int v) {
        for (int neighbor : adjList[u]) {
            if (neighbor == v) return true;
        }
        return false;
    }
};

2.3 Edge List

เก็บทุกเส้นเป็น collection (list / array / vector) ของคู่หรือ struct · ตัวอย่าง: Edges = [(1, 2), (2, 3), (3, 1)]

Space O(|E|) · ข้อดี: เรียบง่าย ประหยัดมาก เหมาะกับ algorithm ที่ทำงานกับ "เส้น" (เช่น Kruskal's MST, Bellman-Ford) · ข้อเสีย: หา neighbor หรือเช็กว่ามีเส้นต้องสแกนทั้งหมด

C++ · EdgeListGraph
struct Edge {
    int src;
    int dest;
    int weight;      // ไม่บังคับ ใช้เมื่อเป็น weighted graph
};

class EdgeListGraph {
private:
    int numVertices;
    vector<Edge> edges;

public:
    EdgeListGraph(int vertices) : numVertices(vertices) {}

    void addEdge(int u, int v, int w = 1) {
        edges.push_back({u, v, w});
    }

    bool hasEdge(int u, int v) {
        for (const auto & edge : edges) {
            if (edge.src == u && edge.dest == v) return true;
        }
        return false;
    }
};

3. Graph Traversal: BFS & DFS

เป้าหมาย: เยี่ยมทุก vertex อย่างเป็นระบบเริ่มจากต้นทาง

  1. BFS (Breadth-First Search): สำรวจ "ทีละระดับ" เยี่ยม neighbor ก่อนลงลึก ใช้ Queue (FIFO)
  2. DFS (Depth-First Search): สำรวจลึกตาม path ให้สุดก่อนแล้ว backtrack ใช้ Stack (LIFO) หรือ recursion

กราฟตัวอย่าง (7 vertex, directed) ที่ใช้ในสไลด์: v₁→v₂, v₁→v₄, v₂→v₄, v₂→v₅, v₃→v₁, v₃→v₆, v₄→v₃, v₄→v₅, v₄→v₆, v₄→v₇, v₅→v₇, v₇→v₆ (adjacency list เรียงตามลำดับนี้) · ลองดูใน Simulation

3.1 BFS

  1. ตั้ง dist ของทุก vertex เป็น ∞ (ยังไม่เยี่ยม)
  2. ตั้ง dist[s] = 0, mark visited, push s เข้า queue
  3. ขณะ queue ไม่ว่าง: pop vertex u หน้าสุด · สำหรับทุก neighbor v ที่ยังไม่ visited: dist[v] = dist[u] + 1, path[v] = u, mark visited, push v

เวลา O(|V| + |E|) (adjacency list) · Space O(|V|) สำหรับ queue และ visited

C++ · BFS
void Graph::BFS(int s) {
    vector<int> dist(numVertices, INT_MAX);
    vector<int> path(numVertices, -1);
    vector<bool> visited(numVertices, false);
    queue<int> q;

    dist[s] = 0;
    visited[s] = true;
    q.push(s);

    while (!q.empty()) {
        int u = q.front();
        q.pop();
        cout << "Visited node: " << u << " at distance " << dist[u] << "\n";

        for (int v : adjLists[u]) {
            if (!visited[v]) {
                visited[v] = true;
                dist[v] = dist[u] + 1;
                path[v] = u;
                q.push(v);
            }
        }
    }
}

3.2 DFS

  1. ตั้งทุก vertex เป็น unvisited
  2. สำหรับแต่ละ vertex u ใน V: ถ้า u ยัง unvisited เรียก DFSVisit(u)
  3. DFSVisit(u): mark u visited · สำหรับแต่ละ neighbor v: ถ้า v unvisited → เส้น (u, v) เป็น Tree Edge แล้วเรียก DFSVisit(v) แบบ recursive · ถ้า v เคยเยี่ยมแล้ว (และยัง active บน call stack) → เส้น (u, v) เป็น Back Edge

เวลา O(|V| + |E|) · Space O(|V|) จาก recursion stack

C++ · DFS
void Graph::DFSVisit(int u, vector<bool>& visited) {
    visited[u] = true;
    cout << "Visited node: " << u << "\n";

    for (int v : adjLists[u]) {
        if (!visited[v]) {
            DFSVisit(v, visited);
        }
    }
}

void Graph::DFS() {
    vector<bool> visited(numVertices, false);
    for (int i = 0; i < numVertices; i++) {
        if (!visited[i]) {
            DFSVisit(i, visited);
        }
    }
}

Trace: DFS จาก v₃

Call stack: v₃ → v₁ → v₂ → v₄ → v₅ → v₇ → v₆ (ลำดับเยี่ยม: v₃, v₁, v₂, v₄, v₅, v₇, v₆) · จาก v₄ เจอเส้น v₄ → v₃ ซึ่ง v₃ ยังอยู่ใน stack → Back Edge (สไลด์ใช้เส้นประสีแดง) · จากนั้น backtrack ตามลำดับ v₆, v₇, v₅, v₄, v₂, v₁, v₃

BFS เทียบ DFS
  • BFS ใช้ queue, ได้ shortest path แบบ unweighted (จำนวนเส้นน้อยสุด)
  • DFS ใช้ stack / recursion, ลึกก่อน, back edge บ่งว่ามี cycle
  • เวลาเท่ากันคือ O(|V| + |E|) เมื่อใช้ adjacency list

4. Disjoint Sets (Union-Find)

4.1 Equivalence Relation & Partition

ความสัมพันธ์ R บนเซต S เป็น equivalence relation ถ้า

  1. Reflexive: aRa ทุก a ∈ S
  2. Symmetric: aRb ก็ต่อเมื่อ bRa
  3. Transitive: ถ้า aRb และ bRc แล้ว aRc

equivalence relation แบ่ง S เป็น equivalence class ที่ไม่ซ้อนกัน (disjoint) — ทุก a อยู่ใน class เดียว และ 2 ตัวอยู่ class เดียวกันก็ต่อเมื่อสัมพันธ์กัน · เป้าหมายของ DSU: รักษา partition นี้แบบ dynamic เมื่อมีการ merge

4.2 Disjoint Set ADT

  • Find(x) — คืนชื่อของ set ที่ x อยู่ (โดยมากคือ representative ของ set)
  • Union(root1, root2) — รวม set ของ root1 กับ root2 เป็น set เดียว
ข้อจำกัด set ต้อง disjoint เสมอ (ไม่มี element ที่อยู่ในหลาย set)

4.3 Tree Representation

แทนแต่ละ set ด้วย tree โดยแต่ละ node ชี้ไปหา parent · root คือ representative · parent ของ root เป็นค่าลบ (เก็บขนาดหรือความสูง) · ตัวอย่าง: ต้นไม้ 1 → {2, 3} กับ 4 → {5} เก็บเป็น s = [-1, 1, 1, -1, 4] (index 1..5)

C++ · Simple Union / Find
// สร้าง Disjoint Sets (vector s เริ่มต้นเป็น -1)
DisjSets::DisjSets(int numElements) : s(numElements, -1) {}

// Simple Union: root2 ชี้ไปที่ root1
void DisjSets::unionSets(int root1, int root2) {
    s[root2] = root1;
}

// Simple Find
int DisjSets::find(int x) const {
    if (s[x] < 0)
        return x;
    else
        return find(s[x]);
}
Worst case อาจได้ต้นไม้สูง N − 1 → find ใช้ O(N) (ลองกด "สร้าง chain" ใน Simulation)

4.4 Smart Union

Union-by-Size

ต่อ tree ที่เล็กกว่า เป็น subtree ของ tree ที่ใหญ่กว่า · เก็บ ขนาดแบบติดลบที่ root (ขนาด 3 → root เก็บ −3) · ผลคือความลึกของ node ใดๆ ไม่เกิน ⌊log₂ N⌋

C++ · unionBySize
void DisjSets::unionBySize(int root1, int root2) {
    if (s[root2] < s[root1]) {       // root2 มีสมาชิกมากกว่า (ติดลบมากกว่า)
        s[root2] += s[root1];         // อัปเดตขนาดของ root2
        s[root1] = root2;             // ให้ root2 เป็น parent ของ root1
    } else {
        s[root1] += s[root2];         // อัปเดตขนาดของ root1
        s[root2] = root1;             // ให้ root1 เป็น parent ของ root2
    }
}

Union-by-Height / Rank

ต่อ tree ที่เตี้ยกว่า เป็น subtree ของ tree ที่สูงกว่า · เก็บ ความสูงแบบติดลบ (เริ่ม −1 = ความสูง 0) · ถ้าสูงเท่ากันให้ root ใหม่ลดค่าลง 1 (ความสูงเพิ่ม 1) · ความลึกกรณีเลวร้ายสุด O(log N)

C++ · unionByHeight
void DisjSets::unionByHeight(int root1, int root2) {
    if (s[root2] < s[root1]) {       // root2 สูงกว่า (ติดลบมากกว่า)
        s[root1] = root2;
    } else {
        if (s[root1] == s[root2]) {
            s[root1]--;               // สูงเท่ากัน → ความสูงเพิ่ม 1
        }
        s[root2] = root1;
    }
}

4.5 Path Compression

Smart union การันตีความสูง O(log N) แต่ทำได้ดีกว่านั้นระหว่าง find: Path Compression — ระหว่าง find(x) ให้ทุก node บน path จาก x ถึง root ชี้ตรงไปที่ root

ตัวอย่าง: chain R ← A ← B ← C · หลัง find(C) → A, B, C ชี้ตรงไปที่ R ทั้งหมด

C++ · find with path compression
int DisjSets::find(int x) {
    if (s[x] < 0) {
        return x;
    } else {
        return s[x] = find(s[x]);   // ตั้ง parent ให้ชี้ตรงไปที่ root ของ find
    }
}

โค้ดเรียกซ้ำสั้นมาก: ไต่ขึ้นไปหา root แล้วตอน recursion คลี่กลับ จะกำหนด parent ของทุก node ที่ผ่านให้เป็น root นั้น

4.6 Complexity

ใช้ Union-by-Rank + Path Compression พร้อมกัน เวลาเกือบเป็น linear: ลำดับของ M finds และ N − 1 unions ใช้ O(M · α(M, N)) เมื่อ α คือ Inverse Ackermann Function ซึ่งโตช้ามากจน α(M, N) ≤ 4 สำหรับค่าที่ใช้จริงทุกกรณี (เช่น N < 265536) → ต้นทุนเฉลี่ยต่อ operation เสมือน O(1)

หมายเหตุ เมื่อใช้ path compression ค่าที่เก็บที่ root ใน union-by-height จะกลายเป็น "ขอบบน" ของความสูง ไม่ใช่ความสูงจริงอีกต่อไป (ใน Simulation สังเกตได้จากความลึกจริงที่แสดง)

4.7 การประยุกต์: Dynamic Maze Generation

  1. เริ่มด้วยกำแพงทุกด้านในตาราง grid
  2. สร้าง Disjoint Sets โดยแต่ละช่องเป็น set ของตัวเอง
  3. ขณะที่จำนวน set > 1: สุ่มเลือกกำแพงที่คั่นช่อง u กับ v → เรียก find(u) และ find(v)
    • ถ้า คนละ set: ทุบกำแพง และ unionSets(find(u), find(v))
    • ถ้า set เดียวกัน: ไม่ทำอะไร (ทุบแล้วจะเกิด loop / cycle)

ตัวอย่างตาราง 3 × 3 ตามสไลด์ (ลำดับกำแพงที่สุ่มได้): (0,1) ✔ · (4,7) ✔ · (1,2) ✔ · (3,4) ✔ · (1,4) ✔ · (6,7) ✔ · (0,3) ✘ ปฏิเสธ (อยู่ set เดียวกันแล้ว) · (5,8) ✔ · (7,8) ✔ → เหลือ set เดียว maze เสร็จ · ดูในหัวข้อ Simulation

หมายเหตุ ค่า find() ที่แสดงในสไลด์บางขั้น (เช่น Step 3 ที่ find(2) = 7) ไม่ตรงกับ partition ที่แสดงข้างๆ (ขณะนั้น {2} ยังอยู่ set เดี่ยว) · Simulation ในหน้านี้คำนวณค่า find จริงด้วย Union-by-Size · ส่วน partition ในแต่ละขั้นตรงกับสไลด์ทุกขั้น

5. Minimum Spanning Tree (MST)

5.1 Spanning Tree

Spanning Tree ของ undirected connected graph G = (V, E) คือ subgraph ที่เป็น tree (ไม่มี cycle) และครอบคลุมทุก vertex ใน V

  • มีอยู่ก็ต่อเมื่อ G เป็น connected
  • มี |V| vertex และ |V| − 1 เส้น พอดี
  • เพิ่มเส้นใดๆ 1 เส้นจะเกิด cycle เดียว ที่ไม่ซ้ำ
  • ลบเส้นใดๆ ออก graph จะ ขาดจากกัน

สำหรับ weighted undirected graph MST คือ spanning tree ที่ผลรวมน้ำหนักต่ำสุด: w(T) = Σe∈T w(e)

กราฟตัวอย่างของหัวข้อนี้ (5 vertex): v₁–v₂ (2), v₁–v₄ (1), v₁–v₃ (4), v₂–v₄ (3), v₂–v₅ (10), v₃–v₄ (2), v₃–v₅ (5), v₄–v₅ (8)

5.2 Prim's Algorithm

Greedy: เริ่มจาก vertex เดียว แล้วโตต้นไม้ทีละ vertex โดยเลือก เส้นถูกสุดที่เชื่อม vertex ในต้นไม้กับ vertex นอกต้นไม้ ทุกรอบ · โครงสร้างคล้าย Dijkstra แต่

  • Dijkstra: ลดระยะรวมจากต้นทาง s → dv = du + c(u, v)
  • Prim: ลดระยะถึง "ต้นไม้ที่กำลังโต" → dv = c(u, v)

โครงสร้างข้อมูล: priority queue เลือกเส้นน้ำหนักน้อยสุดได้อย่างมีประสิทธิภาพ

void Graph::Prim(int s) {
    vector<int> dist(numVertices, INT_MAX);
    vector<int> parent(numVertices, -1);
    vector<bool> inMST(numVertices, false);
    dist[s] = 0;
    priority_queue<pair<int,int>, vector<pair<int,int>>, greater<pair<int,int>>> pq;
    pq.push({0, s});
    while (!pq.empty()) {
        int u = pq.top().second; pq.pop();
        if (inMST[u]) continue;
        inMST[u] = true;
        for (auto edge : adjLists[u]) {
            int v = edge.dest, w = edge.weight;
            if (!inMST[v] && w < dist[v]) {
                dist[v] = w; parent[v] = u;
                pq.push({dist[v], v});
            }
        }
    }
}

5.3 Kruskal's Algorithm

Greedy: รักษา forest ของต้นไม้ · เริ่มด้วย |V| ต้น (แต่ละ vertex คือต้นเดี่ยว/set เดี่ยว)

  1. เรียงทุกเส้นตามน้ำหนักจากน้อยไปมาก
  2. พิจารณาทีละเส้น: ถ้าเชื่อม vertex ใน คนละต้น → รับเข้า MST และรวมสองต้น · ถ้า ต้นเดียวกัน → ทิ้ง (เพราะจะเกิด cycle)

โครงสร้างข้อมูล: Disjoint Set Union (หัวข้อ 4) ตรวจ cycle และ merge ในเวลาเกือบคงที่ · เหมาะกับ Edge List

C++ · Kruskal
vector<Edge> Graph::Kruskal() {
    vector<Edge> mst;
    DisjSets ds(numVertices);
    sort(edges.begin(), edges.end(), [](const Edge& a, const Edge& b) {
        return a.weight < b.weight;
    });
    int edgesCount = 0;
    for (const Edge& edge : edges) {
        int root1 = ds.find(edge.src);
        int root2 = ds.find(edge.dest);
        if (root1 != root2) {
            mst.push_back(edge);
            ds.unionSets(root1, root2);
            edgesCount++;
            if (edgesCount == numVertices - 1) break;
        }
    }
    return mst;
}

6. Shortest Paths

Single-Source Shortest-Path: ให้ weighted graph G = (V, E) และต้นทาง s หา path ที่สั้นที่สุดจาก s ไป ทุก vertex

  • Unweighted: ทุกเส้นมีน้ำหนัก 1 → ใช้ BFS
  • Non-negative weights: w(u, v) ≥ 0 ทุกเส้น → Dijkstra
  • Negative weights: บางเส้น w(u, v) < 0 → ต้องใช้ Bellman-Ford
  • Negative cycle: ถ้ามี cycle ที่ผลรวมน้ำหนักติดลบ shortest path ไม่มีนิยาม (วนซ้ำได้เรื่อยๆ ให้ระยะ −∞)

6.1 Unweighted Shortest Path (BFS)

BFS สำรวจทีละระดับ ครั้งแรกที่เห็น vertex คือ path ที่สั้นที่สุด · เก็บ dist และ path (parent) · O(|V| + |E|)

C++ · unweightedShortestPath
void Graph::unweightedShortestPath(int s) {
    vector<int> dist(numVertices, INT_MAX);
    vector<int> path(numVertices, -1);
    queue<int> q;

    dist[s] = 0;
    q.push(s);

    while (!q.empty()) {
        int u = q.front(); q.pop();
        for (int v : adjLists[u]) {
            if (dist[v] == INT_MAX) {      // v ยังไม่ถูกเยี่ยม
                dist[v] = dist[u] + 1;
                path[v] = u;
                q.push(v);
            }
        }
    }
}

6.2 Dijkstra's Algorithm

Greedy: รักษาเซตของ vertex ที่ "รู้ระยะสั้นสุดแล้ว" (known)

  1. เลือก vertex u ที่ยัง unknown ที่มี tentative distance du น้อยสุด
  2. mark u เป็น known
  3. Relax ทุกเส้น (u, v) ที่ออกจาก u: ถ้า du + w(u, v) < dv ⟹ dv = du + w(u, v)

เงื่อนไข: น้ำหนักทุกเส้นต้อง ≥ 0

C++ · Dijkstra (พร้อม path tracking)
void Graph::Dijkstra(int s) {
    vector<int> dist(numVertices, INT_MAX);
    vector<int> parent(numVertices, -1);   // เก็บ predecessor
    vector<bool> known(numVertices, false);
    dist[s] = 0;

    priority_queue<pair<int,int>, vector<pair<int,int>>, greater<pair<int,int>>> pq;
    pq.push({0, s});

    while (!pq.empty()) {
        int u = pq.top().second; pq.pop();
        if (known[u]) continue;
        known[u] = true;

        for (auto edge : adjLists[u]) {
            int v = edge.dest, w = edge.weight;
            if (dist[u] + w < dist[v]) {
                dist[v] = dist[u] + w;
                parent[v] = u;              // บันทึก predecessor u
                pq.push({dist[v], v});
            }
        }
    }
}
